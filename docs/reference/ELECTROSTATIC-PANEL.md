# Classic electrostatic panel approximation

The 876 × 790 canvas dimensions follow the broad, low frontal proportions of an early full-range electrostatic panel. The permanent perforated screen, wooden cheeks and splayed supports are static CSS materials; no animation or per-frame texture generation is added.

The simulation uses 15 Ω nominal impedance and a conservative 15 W continuous reference. The 84 dB / 2.83 V / 1 m sensitivity reference is represented by a relative 6 dB attenuation in addition to the shared 6 dB signal headroom. These are didactic references, not a measured emulation of a particular physical unit.

The same filter definitions drive the audible response and the displayed graph: two 55 Hz high-pass sections, a broad 0.6 dB midrange contour, a gentle -1.5 dB upper shelf and an 18 kHz low-pass section. The 55 Hz value is a section frequency, with the two-section cascade at approximately -6 dB there. Bass extension, sensitivity and available output remain deliberately limited rather than treating the panel as a modern high-power box.

The existing electrical model uses a fixed nominal resistance; it does not reproduce the real speaker’s frequency-dependent capacitive impedance, transformer, polarization supply, dipole room cancellation, directional treble or arcing. Polarization is assumed available. No additional amplifier is built into this passive speaker.
