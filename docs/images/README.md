# Documentation images

These are captures of **Audio Lab**, made with Chromium on desktop and phone-sized viewports. The overview, Settings screen, mobile properties panel, cable editor, noise controls, sound-signature examples, and power-amplifier gain panel were refreshed on October 28, 2026. UI screenshots use the English interface and the current Audio Lab logo.

The other captures are device-only views last refreshed on October 22, 2026. They show individual equipment and do not include application navigation or an old product wordmark. These illustrations are not photographs or measurements of physical equipment. The stereo system in `visao-geral.png` uses connections in the app's actual signal graph.

The README and wiki use editable English Mermaid diagrams for signal paths. Diagram source files and rendered SVG/PNG versions are in [`docs/diagrams`](../diagrams/README.md).

When updating a capture, use an assembly without personal files or metadata, keep interface labels readable, and confirm that the caption matches the image. For sound-signature graphs, compare the 0 dB reference and the average across each frequency band instead of inferring the indicator from a single peak.
